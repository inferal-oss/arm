# Retained upstream license notices

The `oxigraph@0.5.13` npm archive omits its license files. Its npm metadata names
`https://github.com/oxigraph/oxigraph` (`js/`) as the source repository. Upstream
release tag `v0.5.13` resolves to immutable commit
`2837810c8993da671d496eabf7677d7573c5c522`.

At that commit, `js/Cargo.toml` inherits `version.workspace` and
`license.workspace`; the root `Cargo.toml` declares version `0.5.13` and license
`MIT OR Apache-2.0`. The two full root license files are retained here unchanged.
The upstream root tree contains no separate NOTICE file.

`sources.json` records the exact installed npm archive URL/integrity, release
commit, immutable source URLs and SHA-256 of each license file. The notices
builder uses these full texts only when both the installed package and lock
version match and the lock archive URL/integrity match. It verifies the retained
license hashes before emitting them. Unreviewed versions, archive changes,
missing files and changed texts fail the build.

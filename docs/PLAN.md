## Nested resource pools — newly requested

Implement real custom-resource subpools as a separate feature after the current budget integration. A child reserves a partition from its parent, preserving authority, units and host/global scope. Parent direct claims and sibling partitions compete for the same finite capacity; ancestor limits cannot be bypassed and allocations are not counted twice. Nested policy budgets remain distinct ceilings rather than capacity partitions.

Design review must settle reductions below outstanding descendant use: retain obligations and withhold capacity from the parent until genuinely available. Include immutable safe lineage, depth/cycle bounds, attributed transactional capacity journals, keyed/revisioned mutations, queue/renewal/restart behavior, deletion/drain and existing budget-limit inheritance. Then implement backend/CLI and matching web/TUI tree views, with tests for concurrent sibling allocation, deficit/reclaim races, ancestor enforcement and restart. Not implemented yet.
